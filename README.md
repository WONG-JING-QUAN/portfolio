## Built with

Hand-written HTML, CSS and vanilla JavaScript, hosted on GitHub Pages. No framework or build step.
Fonts from Google Fonts, icons from Font Awesome and card tilt from vanilla-tilt.js.

## Run it locally

```
python -m http.server 8000
```

Run this in the repository folder, then open http://localhost:8000.
